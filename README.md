# Felsök ett nätverk

Ett interaktivt portfolio-projekt som visar hur jag tänker kring systematisk felsökning av nätverksproblem, från symptom och fakta till test, isolering och verifiering.

## Live Demo

[**→ Öppna den interaktiva hemsidan**](https://aleks5246.github.io/Felsok-ett-natverk/)

## Vad projektet visar

- Systematisk nätverksfelsökning
- IP-adressering och connectivity
- VLAN och routing
- DHCP och DNS
- Brandväggar och filtrering
- Vanliga felsökningsverktyg
- Dokumentation och problemlösning

## Felscenarier

Projektet innehåller simulerade scenarier för:

1. Klient får ingen IP-adress
2. Klient kan inte nå ett annat nät
3. DNS fungerar inte
4. Servern nås men tjänsten svarar inte

All testdata på hemsidan är tydligt simulerad och ska inte tolkas som mätningar från ett verkligt produktionsnätverk.

## Teknik

- HTML
- CSS
- JavaScript
- SVG

Projektet är byggt som en fristående `index.html` utan externa bibliotek.

## Syfte

Syftet är att visa hur jag angriper nätverksproblem steg för steg istället för att bara fokusera på den slutliga lösningen.
